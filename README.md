# Industry 4.1 Production Management System

A Full Stack Industry 4.1 Production Management System developed using React.js, ASP.NET Core Web API, and SQL Server.

## Features

* Dashboard Analytics
* User Management
* Machine Management
* Shift Management
* Production Monitoring
* Reports Generation
* Interactive Charts & Analytics

## Technologies Used

### Frontend

* React.js
* Vite
* CSS

### Backend

* ASP.NET Core Web API
* C#

### Database

* SQL Server

## Dashboard Screenshots

* Production Module
* Reports Module

## Project Structure

```text
frontend/      -> React Frontend
Industry4.1/   -> ASP.NET Core Backend
```

## How to Run

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd Industry4.1
dotnet run
```
